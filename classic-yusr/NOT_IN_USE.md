# Classic Yusr: not in use now

This folder holds the original Yusr app exactly as it was before Yusr's functions were merged into Kharadhu. It is kept for reference and for carrying over migrations, security rules and the Wasiyyah & Amanah spec.

- Nothing here is built, tested or deployed. The GitHub Actions workflows in `classic-yusr/.github/` are inactive because GitHub only runs workflows from the repository root.
- The new app is Kharadhu. Its spec is `docs/kharadhu-prd.md` at the repository root.
- Do not add new work here.
